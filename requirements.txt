# Python application bootstrap for Phantom AI God

This project uses a minimal and safe Python stack:
- FastAPI for the HTTP API
- Pydantic for validation
- Python standard library for internal logic
- pytest for unit tests

## Requirements

- Python 3.11+
- pip
